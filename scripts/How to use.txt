Hew7 setup and undo
===================

Before you start (on the TV):
  Settings > System > About > tap "Build" 7 times to unlock Developer options.
  Settings > System > Developer options > switch on USB debugging (and Network debugging if listed).
  Note the TV's IP address (Settings > Network and Internet > your network).

On the computer:
  Keep Hew7.apk in this folder.
  If adb isn't installed, download Google's "SDK Platform-Tools for Windows" and unzip it here,
  so there is a "platform-tools" folder next to these scripts.

In the commands below, replace YOUR-TV-IP with your TV's IP address.

Set up Hew7 (right-click this folder > Open in Terminal, then):
  powershell -ExecutionPolicy Bypass -File Hew7-Setup.ps1 -TvIp YOUR-TV-IP
  Then, on the TV, switch on "Hew7 Helper" on the Accessibility page that opens.

Undo Hew7 (Google TV's home comes back, permissions removed, Hew7 removed):
  powershell -ExecutionPolicy Bypass -File Hew7-Undo.ps1 -TvIp YOUR-TV-IP -Uninstall

Add -DryRun to any of these to see what it would do without changing anything.

Setup saves the TV's original settings to hew7-tv-backup-<TV address>.json in this folder; Undo
uses it. Keep these files with the scripts (one per TV). Address the TV by the same IP each time.
If the TV asks "Allow USB debugging?", choose "Always allow from this computer".
